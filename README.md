# ProductSignal

**ProductSignal is a product discovery workspace for turning customer feedback into evidence-backed product decisions.**

### Live demo

**[Open ProductSignal](https://product-signal-102xnzz1v-rlatos-projects.vercel.app/)**

## Why I built it

Product teams collect plenty of customer feedback, but the hard part is deciding what the feedback actually means and what deserves action.

I built ProductSignal as a small product experiment around that problem. The goal is to help a PM move from raw customer feedback to recurring themes, opportunities, and prioritization while keeping the underlying evidence visible.

The product is intentionally designed around a simple principle:

> **AI can help a PM find signal, but it should not make the product decision for them.**

## The workflow

1. **Collect feedback** from customer conversations and other sources.
2. **Identify themes** and recurring problems.
3. **Review evidence** behind each theme rather than accepting an insight at face value.
4. **Create opportunities** from validated customer problems.
5. **Prioritize** using impact, effort, and confidence.
6. **Make the product decision**: investigate, build, or leave it alone.

## What this demonstrates

- Product discovery and continuous customer feedback
- Evidence-based prioritization
- Clear separation between insight and product judgment
- Designing for a small product team with a lightweight workflow
- Responsive web product design for desktop and mobile

## Product decisions behind the MVP

**Keep evidence visible.** A theme is only useful if a PM can trace it back to customer feedback.

**Keep AI assistive.** The product should accelerate synthesis and challenge thinking, not become an automated roadmap generator.

**Keep prioritization simple.** The MVP focuses on impact, effort, and confidence rather than pretending that a formula can replace product judgment.

**Optimize for speed.** This is intentionally a focused product workflow rather than a full product management suite.

## Current MVP

The live demo includes:

- Customer feedback capture
- Feedback review
- Theme and evidence views
- Product opportunity review
- Prioritization workflow
- Responsive mobile experience

The current portfolio demo uses a lightweight analysis experience so it can run as a simple, publicly accessible web application without requiring visitors to provide an API key.

## What I would build next

If this moved beyond the portfolio MVP, the next steps would be:

- Connect real AI-assisted synthesis to customer feedback
- Add evidence-level links from themes to source feedback
- Add CSV/text import
- Add saved workspaces and feedback history
- Add configurable prioritization criteria
- Add experiment tracking and outcome measurement
